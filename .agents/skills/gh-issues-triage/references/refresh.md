# Odświeżenie zestawienia

Ładuj, gdy użytkownik prosi o aktualizację lub odświeżenie poprzedniego zestawienia.

Zachowaj ostatnie uzgodnione filtry z tej rozmowy, chyba że użytkownik je zmieni. Nie odtwarzaj filtrów z pamięci starych raportów. Ponownie odczytaj dane; nie zastępuj bieżących danych poprzednią tabelą.

Wskaż zmiany względem poprzedniej tabeli tylko na podstawie ponownego odczytu: nowe pozycje, zmiany statusów i powody usunięcia, w tym zamknięcie issue lub usunięcie z projektu.
