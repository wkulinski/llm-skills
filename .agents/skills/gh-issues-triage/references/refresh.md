# Odświeżenie zestawienia

Ładuj, gdy użytkownik prosi o aktualizację lub odświeżenie poprzedniego zestawienia.

Zachowaj ostatnie uzgodnione filtry z tej rozmowy, chyba że użytkownik je zmieni, ale nie poprzedni układ kategorii: kategorie tematyczne wyprowadź na nowo z bieżących issues. Nie odtwarzaj filtrów z pamięci starych raportów. Ponownie odczytaj dane; nie zastępuj bieżących danych poprzednim zestawieniem.

Wskaż zmiany względem poprzedniego zestawienia tylko na podstawie ponownego odczytu: nowe pozycje, zmiany statusów i powody usunięcia, w tym zamknięcie issue lub usunięcie z projektu. Podaj je zwięźle w odpowiedniej sekcji raportu, bez dodatkowej sekcji głównej.
